# Additional Engineering Toolbox Coverage Review

**Planning/recommendation only.** The following are candidate additional disciplines not yet given detailed per-feature inventories. Priority indicates potential usefulness and shared mathematical value, not implementation approval or completeness. Each candidate should have a searchable dedicated toolbox only where it offers substantial discipline-specific workflows; otherwise link shared tools by category. Preserve existing toolboxes and avoid duplicating common algorithms.

**Catalog count:** 22 candidate domains, **not** 22 implemented toolboxes. High-priority shared-core services (numerical methods, optimization, reliability, units, visualization) should be reusable libraries rather than duplicated discipline-specific engines. Cross-domain feature IDs should be canonical and status evidence-based.
